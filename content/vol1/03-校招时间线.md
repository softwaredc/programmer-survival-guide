# 校招时间线：提前批 / 秋招 / 春招全日历

## 1. 三十秒自检

- [ ] 你打算"等九月份再开始准备"
- [ ] 你不知道提前批和正式秋招的区别
- [ ] 你错过了提前批，觉得已经完了
- [ ] 你考研失败，不知道现在还能不能补救
- [ ] 你没有自己的投递记录表，靠记忆管理进度

打勾 ≥2 个，往下读。**第一条是所有错误里最常见也最贵的一个。**

## 2. 结论先行

**校招最重要的一件事：秋招不是九月开始的，是六月就该动手的。**

真实的时间结构是这样的（具体月份每年略有浮动，请以当年的实际情况为准）：

| 阶段 | 时间区间 | 特点 |
|---|---|---|
| **暑期实习** | 大三升大四的暑假前后 | 转正率是校招里最高的通道之一 |
| **提前批** | 大约 7~8 月 | 门槛高、hc 少，但竞争相对小、流程快；**多数可以不影响正式批** |
| **秋招正式批** | 大约 8~10 月 | 主战场，hc 最多，竞争最激烈 |
| **秋招补录** | 大约 11~12 月 | 有人拒 offer 之后放出的坑，容易被忽视 |
| **春招** | 次年 2~4 月 | hc 明显少，是补充不是主力 |
| **毕业后的社招门槛** | 毕业后 | 失去应届身份，走社招逻辑，要求完全不同 |

**三条最重要的判断：**

1. **提前批一定要投。** 它的成本极低（多数不影响正式批），而一旦通过就提前结束战斗。
2. **秋招也会补录。** 很多人在 11 月就停止投递了，但 11~12 月的补录竞争反而小。
3. **应届身份有明确时效，且非常值钱。** 不要为了任何事情轻易放弃它（详见[三方协议](07-三方协议.md)）。

## 3. 现在就做

| 时间窗 | 动作 |
|---|---|
| **今天** | 建一张投递记录表（模板见第 4 段），**每一份投递都记下来** |
| **今天** | 确认自己现在的月份处在哪个阶段，倒推还剩多少准备时间 |
| **本周** | 简历至少改到可以给三个人看，收集完反馈再投（不要第一版就海投） |
| **本月** | 如果临近提前批：准备一个 3 分钟自我介绍 + 三个项目的完整叙述 |
| **持续** | 每天定量投递（建议 5~10 份），并记录反馈。**没有反馈就调整简历，不要机械海投** |

## 4. 可直接抄的话术 / 模板

### 投递记录表（必须建，这是管理校招的唯一有效工具）

| 公司 | 岗位 | 投递日期 | 渠道 | 当前进度 | 下次跟进 | 备注 |
|---|---|---|---|---|---|---|
| | | | 官网/内推/公众号 | 简历通过/笔试/一面/二面/HR面/offer | | |

要点：**这张表的价值在于让你知道问题出在哪一环。**
- 投 30 份简历通过率 < 20% → **简历有问题**，停止投递去改简历
- 简历通过但一面挂得多 → **项目叙述或基础知识有问题**
- 都过了但拿不到 offer → **可能是 HC 或薪资倒挂问题**

---

**场景一：向学长学姐请求内推（成功率最高的渠道）**

> 「学长/学姐你好，我是 XX 届的 XX，看到贵司 XX 岗位在招，非常想试试。
> 不知道方不方便帮我内推一下？我把简历放在附件里了，不着急，你方便就行。」

要点：**附上简历（PDF）+ 给对方方便的余地。** 不要发一大段自我介绍，对方没时间看。

**场景二：投递后长时间无进展时跟进**

> 「您好，我于 X 月 X 日投递了 XX 岗位（简历编号/申请 ID：XX），
> 想了解一下目前的进度。如果没有结果也没关系，打扰了。」

要点：**加上编号，显得有条理；语气给对方台阶。** 跟进一次是合理的，不要反复追问。

**场景三：错过秋招之后的补救话术（给招聘方或 HR）**

> 「您好，我今年因为 XX 原因错过了秋招的主要批次。
> 想请问一下，目前是否还有补录的岗位？或者我是否可以投递明年的春招？」

**场景四：笔试/面试时间冲突或想要争取机会**

> 「您好，我这边同时进入了两个流程，都非常想去。
> 请问方便告诉我这边目前的进度和接下来大致的安排吗？我想尽量协调时间。」

要点：**诚实且简洁。** 不要虚构 offer 来催流程，很容易被识破。

### 各阶段准备重点（倒推时间表）

```
提前 3 个月：确定方向（见「选方向」） + 做完 1~2 个项目
提前 2 个月：简历定稿 + 开始刷题（每天 2~3 题）
提前 1 个月：投递前最后校准（找人 mock 面试一次）
投递期：     每天定量投递 + 记录 + 每周复盘
面试期：     每次面试后当天复盘（记下被问倒的题）
```

## 5. 五个常见错误

1. **等九月才开始准备**
   → 后果：这是最典型的一个错误。等到你开始投简历时，别人已经面试了一个多月
   → 正确做法：**至少提前三个月**。简历和项目是可以提前做完的

2. **第一版简历就拿去海投**
   → 后果：把最好的机会消耗在测试简历上。**第一批投递的公司往往是你的目标公司**
   → 正确做法：**先投几家不太在意的热身**；或者至少给三个不同的人看过

3. **不记录投递、不复盘面试**
   → 后果：投了几十家不知道哪家到哪一步；每次面试被问倒的都是同一类题
   → 正确做法：**投递表 + 面后当天复盘**

4. **11 月之后就放弃**
   → 后果：错过竞争反而更小的补录窗口
   → 正确做法：**补录确实存在**。有人拒 offer、有部门拿到新 hc。**继续投到十二月**

5. **为了一个"还不错的 offer"停止所有动作**
   → 后果：失去了拿到更好 offer 的可能，也没有谈判筹码
   → 正确做法：**拿到第一个 offer 之前不要停；拿到之后也不要立刻停**（注意三方协议的约束，见[三方协议](07-三方协议.md)）

## 6. 真实案例（脱敏）

**案例 A · 提前三个月准备的人**

某同学在大三结束的那个暑假前（大约五月）就确定了方向，用两个月做完了一个完整项目，七月投提前批时被捞了一次，八月拿到 offer。**他整个秋招九月就结束了。** 剩下的时间他用来准备毕业设计。

**对比同期另一位同学**：九月开始投简历，十月才开始刷题，十一月面到几家但因为准备不足挂在一面，最后在春招拿到了明显更差的 offer。

**差别不在能力，在时间。** 前者的项目是在没有压力的情况下做的，后者是在一边焦虑一边补。

**案例 B · 补录捡漏**

有人在十二月初已经准备放弃，抱着"再投一周"的心态投了几家。其中一家正好有人拒了 offer，他在一周内走完了流程并拿到 offer。**他后来说：那一周是那半年里性价比最高的一周。**

**案例 C · 没有记录表的代价**

另一位同学投了 40 多份，两个月后完全忘记哪家投过、哪家在流程中。有一次被通知面试时，他完全想不起来自己投的是什么岗位。**这不是能力问题，是纯管理问题。**
