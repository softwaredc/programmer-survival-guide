# 实习：什么时候找、怎么找、实习期该拿到什么

## 1. 三十秒自检

- [ ] 你不确定大几找实习最合适
- [ ] 你没有实习经历，简历一片空白
- [ ] 你实习期间主要在打杂，说不清自己做了什么
- [ ] 你不知道实习结束该要什么
- [ ] 你以为实习工资低是"应该的"

打勾 ≥2 个，往下读。**第三条是最容易被浪费的一次机会，第五条是很多人白白吃亏的地方。**

## 2. 结论先行

**一段实习真正的价值，不是那点工资，而是这三样能带走的东西：**

1. **一段能写进简历的具体经历**（有数字、有结果）
2. **一个能给你背书的推荐人**（这是最容易被忽略、但也最值钱的一项）
3. **一次转正的机会**（或者至少，一次真实的行业认知）

**如果实习结束时你只拿到了工资，那你亏了。**

关于时间的几个判断：

- **什么时候找**：越早越好，但不要早到什么都不会。**能独立写一个完整模块的阶段**就是最好的时机
- **多久合适**：**三个月是底线**。短于三个月的实习，多数公司不会认为你真的做过什么
- **没有实习怎么办**：用**可展示的项目 + 开源贡献**替代。这不是安慰话，确实有用——前提是你的项目真的能用、能讲清楚

## 3. 现在就做

| 时间窗 | 动作 |
|---|---|
| **今天** | 如果你正在实习：**今天就去确认你这段时间的产出能不能量化**（不是以后，是今天） |
| **今天** | 列出你所在团队里最了解你工作的 2 个人——他们就是你未来的推荐人 |
| **本周** | 主动向主管要一件"有明确产出"的事（话术见第 4 段） |
| **本周** | 开始维护一份实习周记：这周做了什么、结果是什么、学到了什么 |
| **实习中期** | 明确问一次："我有没有转正的可能？"（见第 4 段话术三） |
| **实习结束前一个月** | 要到实习证明 + 推荐人联系方式 |

## 4. 可直接抄的话术 / 模板

**场景一：向主管要"有产出"的工作（实习生的核心难题）**

> 「我来这边有一段时间了，手上的事情也在逐步上手。
> 我想请教一下：有没有什么相对完整的、我可以从头跟到尾的事情可以让我试试？
> 我希望这段时间结束的时候，能有一个完整的交付。」

要点：**"从头跟到尾"和"完整的交付"是两个关键词。** 打杂和做事的差别就在这里。多数主管听到这句话会给机会——因为实习生主动要活的很少。

**场景二：被安排做杂活时**

> 「这个我可以做。我想确认一下大概需要多久——
> 因为我还想问一下，做完之后我那边还有 XX（你正在做的事），
> 如果时间排得开的话，我想把那个也推进一下。」

要点：**不要拒绝杂活**（这会被认为态度有问题），而是**主动管理你的时间分配**。

**场景三：问转正（很多人不敢问的一件事）**

> 「我想请教一下：我这边表现还有哪些地方需要提升？
> 另外想了解一下，团队今年有转正的名额吗？我想知道自己的情况。」

要点：**必须在实习中期问，不要等到最后一周。** 如果答案是没有名额，你还有时间去投秋招；如果等到最后才知道，就来不及了。

**场景四：实习结束时请求推荐**

> 「这段时间非常感谢你的指导，我学到了很多。
> 我接下来要准备秋招了，如果在简历或者背调的时候需要联系你，
> 方便留一个你的联系方式吗？」

要点：**这句话在实习结束那天说，比半年后说有用一百倍。** 那时你还新鲜在对方的记忆里。

**场景五：没有实习经历时，简历怎么补**

```
✅ 可以写：
· 个人项目：XX 系统（GitHub 链接）—— 用一句话说清楚它解决了什么问题
· 开源贡献：给 XX 项目提过 PR（merged）
· 竞赛 / 课程大作业（如果足够完整）

❌ 不要写：
· "熟练掌握 XX"（没有产出支撑的说法）
· 跟教程敲的 demo（面试官两句话就能问穿）
```

## 5. 五个常见错误

1. **实习期间不主动，全程等人安排**
   → 后果：三个月过去，简历上只能写"参与日常业务需求开发"
   → 正确做法：**主动要一次完整的事**。这是实习生唯一需要学的一件事

2. **不问转正，默认"表现好就会被留"**
   → 后果：名额是提前确定的，跟你的表现常常无关。很多人到最后一周才知道今年没有 HC
   → 正确做法：**实习中期（第 4~6 周）明确问一次**

3. **没留下任何可以联系的人**
   → 后果：秋招时简历上一个背书人都没有，而别人有学长学姐内推
   → 正确做法：**实习结束时至少要到一位推荐人的联系方式**

4. **接受明显低于合理范围的实习报酬**
   → 后果：这是实际会发生的事，而且不少实习生默认这是"应该的"
   → 正确做法：实习生的权益保障有其特殊性，**工资明显过低或长期无偿的情况，建议先了解相关规定再决定**。至少记住一点：**你被拖欠的部分有权要回来**

5. **把"大厂实习"当成唯一目标**
   → 后果：错过小公司里能真正做事的机会。在大厂实习三个月只做了一件事的一角，不如在小公司跟完一个完整项目
   → 正确做法：**实习的核心指标是"能不能讲出完整的故事"**。公司名气是加分项，不是目的

## 6. 真实案例（脱敏）

**案例 A · 把实习用足了的人**

某学生在一家中型公司实习三个月。他在第二周就按第 4 段场景一的话术要了一件完整的事（一个内部小工具的开发）。实习结束时他带走了三样东西：一个能讲清楚的项目、一位愿意帮他做背调的主管、以及一个转正 offer（他没接，去了更好的地方，但那个 offer 成了他谈薪的筹码）。

**做对了**：第二周就开口要活，而不是等到第三个月。

**案例 B · 浪费了实习的人**

另一位同学在某大厂实习三个月，团队很大，他被安排在一个模块的边缘做数据整理。三个月结束时他发现自己完全讲不清这个系统的全貌，简历上只能写一行。

**做错了什么**：他觉得"大厂光环就够了"，没有主动去理解整块业务，也没有要到任何推荐人。

**他的复盘**：「我以为公司名字会替我说话。面试的时候才发现，人家问的是你做了什么。」

**案例 C · 没有实习但补救成功的**

有人因为准备考研错过实习季，秋招时简历空白。他花了两个月做了一个完整的小项目（一个解决了他自己真实需求的小工具，有用户、有迭代），写了完整的文档。**这份项目在面试中被反复追问，反而成了他最强的证明材料。**
