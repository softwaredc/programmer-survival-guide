# Offer 选择：把 offer 换算成时薪再比

> **这是卷一最重要的一章。** 如果你只有时间读一章，读这一章。

## 1. 三十秒自检

- [ ] 你在比较 offer 的月薪数字
- [ ] 你没有把通勤时间算进去
- [ ] 你不知道自己的期权该怎么估值
- [ ] 你在纠结"大厂 vs 小公司"
- [ ] 你准备选薪资高的那个

打勾 ≥2 个，往下读。**如果你打算直接选薪资高的那个，请务必先做完第 3 段的计算。**

## 2. 结论先行

**月薪不能直接比。唯一诚实的比较口径是"真实时薪"。**

原因很简单：**一个月薪 25K、每天朝九晚九、单程通勤 1.5 小时的 offer，真实时薪可能低于一个月薪 18K、通勤 20 分钟、准点下班的 offer。**

完整算法：

```
真实时薪 =（年总收入）÷（全年实际投入小时数）

【分子 · 年总收入】
= base × 12
+ 年终奖（期望值，不要按最好情况算）
+ 绩效奖金（按实际发放概率折算）
+ 期权 / RSU（大幅折价，见下）
+ 公积金（公司缴纳部分 × 2 —— 这是实打实的钱）
+ 补贴（餐补、交通、住房）

【分母 · 全年实际投入小时数】
=（每周在岗小时 + 每周通勤小时 + 每周在家加班/oncall 小时）
× 52（或扣掉年假后的工作周数）
```

**关于期权：保守原则 —— 绝大多数情况下，把它当作 0 来比。**

如果你一定要算进去，建议至少做三次折价：
1. 按公司的**融资阶段**打折（越早期风险越大）
2. 按**归属周期**打折（四年归属，年化摊薄）
3. 按**流动性**打折（非上市公司的股权几乎无法变现）

三个 offer 比较完毕之后，再看**非薪资因素**：

| 因素 | 合理的权重 |
|---|---|
| **能不能学到东西**（第一份工作最重要） | 极高 |
| 直属上级是谁 | 很高（很多人离职是因为上级） |
| 业务是否在增长 | 高 |
| 公司名气 | **中等** —— 它有用，但不该压过前三项 |
| 通勤时间长短 | 中高（这是每天都会发生的损耗） |

**场景一：问清楚真实工作时长（这是最关键的一个问题）**

> 「方便问一下团队日常的工作节奏吗？
> 一般是几点到几点？周末需要 oncall 吗？频率大概是多少？」

要点：**不要问"加班多吗"**（会得到外交辞令）。**问具体的时间点和频率**，对方很难含糊。

如果你能联系到未来同事（比如通过脉脉、学长），更高效的问题是：

> 「想请教一下，大家一般是几点下班的？」

**场景二：确认年终奖口径（差别可能有好几个月工资）**

> 「想确认一下年终奖的部分：是固定的 13 薪，还是会有浮动？
> 如果是浮动的，一般区间是多少？往年实际发放的情况大概是怎样的？」

要点：**"往年实际发放情况"这半句是重点。** 很多公司承诺"2~6 个月"，实际常年发 1 个月。

**场景三：确认公积金**

> 「公积金的缴纳基数和比例是怎么确定的？是按实际工资还是按某个基数上限？」

要点：**这是很多人忽略的一笔钱。** 按 12% 比例、公司和员工各缴一份的话，实际相当于多了一笔可观的收入（尤其在买房时）。

**场景四：有一个 offer 但想等另一个（延期的说法）**

> 「非常感谢这个机会，我这边也很想去。
> 我目前还有另一个流程在最后阶段，大概需要 X 天出结果。
> 方便给我 X 天的时间考虑吗？」

要点：**给出明确的天数和理由，比含糊地说"我再想想"更有效。** 通常 3~7 天是被接受的。

**场景五：拒绝了 Offer 但想留门**

> 「非常感谢你们的认可，这次因为 XX 原因我不能加入。
> 我对团队印象很好，希望以后有机会再合作。」

要点：**行业很小。** 三年后你可能还想来这里。

## 5. 五个常见错误

1. **只比月薪**
   → 后果：这是最常见也最容易亏的一个错误。一个月薪高 30% 但工时高 60% 的 offer，实际是降薪
   → 正确做法：**必须算真实时薪**

2. **把期权按最好情况估值**
   → 后果：用公司给的"未来估值"折算，把一张概率很低的彩票当成了确定的钱
   → 正确做法：**非上市公司的期权，在做决策时按 0 计**。如果它后来值钱了，那是意外之喜

3. **忽略公司名气的正确用法**
   → 后果：为了名气去了一个学不到东西的岗位；或者相反，完全忽视平台的背书价值
   → 正确做法：**名气是有用的，但它的作用是"降低你下一次求职的门槛"。所以它的价值在第一份工作和下一次跳槽时最明显，之后迅速衰减**

4. **没问清楚直属上级是谁**
   → 后果：这是导致"入职三个月就想走"的头号原因
   → 正确做法：**尽量争取一次和未来主管的沟通**。他问你的方式、他答你的态度，决定了你未来一两年

5. **在两个都不错的 offer 之间纠结太久**
   → 后果：机会会被撤回，而你纠结的那两个变量的差距通常很小
   → 正确做法：**把差距量化。如果真实时薪差距小于 10%，那么这个差别不值得纠结——选那个让你更想去的**

## 6. 真实案例（脱敏）

**案例 A · 算完之后反转了**

某应届生手上有两个 offer：
- A：月 base 22K，某知名公司，朝九晚九，单程通勤 1 小时 20 分钟
- B：月 base 17K，某公司，早十晚七，单程通勤 25 分钟

按月薪看 A 明显更好。算了真实时薪之后：

| | A | B |
|---|---|---|
| 每周在岗 | 约 60 小时 | 约 45 小时 |
| 每周通勤 | 约 13.3 小时 | 约 4.2 小时 |
| **每周总投入** | **约 73 小时** | **约 49 小时** |
| 月薪差 | +29% | — |
| **真实时薪** | **低于 B** | **高于 A** |

**A 的真实时薪比 B 低。** 他选了 B，一年后反馈很好——多出来的时间他用来做了一个开源项目，反而成了后来跳槽的资本。

**案例 B · 被年终奖坑了**

有人在两个 offer 之间选了承诺"年终奖 2~6 个月"的那个，放弃了"固定 13 薪"的。结果第一年年终发了一个月。**因为他没问清楚口径。**

**教训**：**"2~6 个月"在多数公司等于"1~2 个月"。** 问历史实际发放情况比问区间有用。

**案例 C · 期权按 0 算的人做对了什么**

某早期员工在两个 offer 之间纠结，其中一家给了不少期权。他按本文的原则把期权按 0 计算，基于此选了现金更多的那家。**三年后那家有期权的公司没有成功。** 他的判断不一定每次都对，但方法是对的——**决策要基于大概率，不是基于最好的可能性。**
