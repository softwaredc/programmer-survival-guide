# 试用期：前 90 天的生存动作清单

## 1. 三十秒自检

- [ ] 你不知道试用期到底多长、工资能不能打折
- [ ] 你入职三周了还没交付任何东西
- [ ] 你不确定谁决定你能不能转正
- [ ] 你不知道自己的试用期考核标准
- [ ] 你在试用期就被安排了大量杂活

打勾 ≥2 个，往下读。**第三条是决定性的——搞清楚这一点比做任何工作都重要。**

## 2. 结论先行

**试用期不是单向的观察期，是双向确认期。** 你在确认这家公司值不值得待的时间，往往比公司确认你的时间更短——**因为你有选择，而一旦过了试用期通常就不那么容易走了。**

关于试用期的基本规则（《劳动合同法》相关规定）：

- 试用期长度与劳动合同期限挂钩：**合同期限三个月以上不满一年的，试用期不得超过一个月；一年以上不满三年的，不得超过二个月；三年以上及无固定期限的，不得超过六个月**
- **同一用人单位与同一劳动者只能约定一次试用期**
- 试用期工资**不得低于**本单位相同岗位最低档工资或者劳动合同约定工资的 **80%**，并不得低于当地最低工资标准
- 劳动合同期限不满三个月的、**以完成一定工作任务为期限的**、以及非全日制用工，**不得约定试用期**

**前 90 天的三个核心动作：**

1. **搞清楚谁决定你的转正**（这是最重要的一件事）
2. **交付一个能被看见的小成果**（不要等到三个月）
3. **建立至少一段可求助的关系**（不只是上级）

## 3. 现在就做

| 时间窗 | 动作 |
|---|---|
| **今天** | 确认你的试用期长度、工资是否打折、社保是否从入职当月缴 |
| **第 1 周** | 明确问到：我的转正标准是什么？谁签字？（话术见第 4 段） |
| **第 1 周** | 记下团队里每个人的名字和职责，尤其是你需要对接的人 |
| **第 2~4 周** | 交付第一个**小的、完整的、可被验证的**成果 |
| **第 30 天** | 主动和上级做一次 1on1，问"我目前的表现是否符合预期" |
| **第 60 天** | 检查三项：谁决定转正、标准是什么、我现在处在什么位置 |
| **第 90 天** | 准备转正答辩 / 总结材料 |

## 4. 可直接抄的话术 / 模板

**场景一：问清楚转正标准（第一周必问）**

> 「我想确认一下试用期的情况，方便好好安排这几个月：
> 试用期结束后转正是怎么评估的？有哪些具体的标准？
> 大概什么时候会做这个评估？」

要点：**这个问题在第一周问，显得你有规划；在第三个月问，显得你心虚。** 时机决定效果。

**场景二：主动请求定期反馈（第 30 天）**

> 「我来了一个月了，想和你对一下目前的状况。
> 你觉得我这段时间的表现符合预期吗？有没有哪些地方需要调整的？」

要点：**"有没有需要调整的"比"我是不是表现好"更容易得到真话。** 而且万一有问题，你还有两个月时间修正——这是这句话真正的价值。

**场景三：被安排过多杂活时**

> 「这些我可以做，没问题。
> 不过我想确认一下优先级——是不是希望我这段时间先把 XX 做上手，
> 这些临时的事情如果影响到那件事的排期，我可能要和你确认一下。」

要点：**不拒绝，但要让对方意识到你在做取舍。** 试用期的关键是让别人看到你的产出，而不是你的服从。

**场景四：发现自己完全无事可做时（很多人不好意思问）**

> 「我这边目前手上的事情暂时不多，想问一下：
> 有没有什么是我可以先看着的？或者团队现在有没有卡住的事情我可以帮忙？」

要点：**无事可做在试用期是最危险的状态。** 主动要去比什么都强。

**场景五：感觉环境不对，想走的时候**

> 如果试用期里你发现明显的问题（与面试描述严重不符、工作内容完全不是面试时说的样子、或团队状况很差），
> **试用期是你最该走的时机**——此时离职的成本最低，简历上也几乎没有痕迹。
>
> 沟通方式：
> 「这段时间非常感谢大家的帮助。
> 不过我发现这个岗位的实际内容和我的预期有些差距，我可能不太适合这里。
> 我想尽早说明，这样对大家的时间也更好。」

### 前 90 天检查清单

```
第 1 周
□ 确认试用期长度、工资、社保缴纳起始月
□ 问清楚转正标准与评估人
□ 记下团队分工，找到你最常对接的三个人的名字

第 2~4 周
□ 完成环境搭建并跑通一个完整流程
□ 交付第一个小成果（哪怕只是一个 bug fix，但要完整）
□ 主动约一次 1on1

第 30~60 天
□ 承担一个稍大的任务
□ 至少一次主动同步你的进展（邮件或周报）
□ 判断：这个地方和我说的一样吗？

第 60~90 天
□ 准备转正材料
□ 确认转正流程与时间点
□ 如果打算走：现在是最好的时机
```

## 5. 五个常见错误

1. **不知道谁决定你的转正**
   → 后果：这是本节最重要的一条。你可能做对了所有事，但决定权在另一个你没注意到的人手里
   → 正确做法：**第一周就问清楚"谁评估我"**

2. **前三个月只做杂事，没有可展示的产出**
   → 后果：转正评估时没有人能说出你做了什么
   → 正确做法：**哪怕是小事，也要做出一件完整的、可被点名说出来的成果**

3. **不与任何人建立关系**
   → 后果：没人了解你，也没人替你说话
   → 正确做法：**至少和三位同事建立"可以顺便问一句"的关系**。方法很简单：遇到问题先尝试自己查，查不到再带着你的思考去问

4. **发现明显不对却拖着不走**
   → 后果：试用期是离职成本最低的窗口，错过之后你就要带着这段经历重新求职
   → 正确做法：**如果环境和面试描述严重不符，尽早决定。** 试用期离职在简历上几乎无痕

5. **在试用期就过度表现**
   → 后果：承诺了超出能力的事，或者建立了不可持续的节奏（比如天天加班到最晚），三个月后绷不住
   → 正确做法：**稳定交付比惊艳一次重要。** 试用期评估看的是可靠性，不是爆发力

## 6. 真实案例（脱敏）

**案例 A · 问对了问题**

某新人入职第一周就约了一次 1on1，问了两件事："转正怎么评估"和"你觉得我前三个月最重要的是做好哪件事"。主管给了非常明确的答案，他照着做，三个月顺利转正并且评价很好。

**第二年他才知道**：同一批进来的另一个人，直到第三个月才问转正标准，而当时主管已经在讨论他的问题了。

**差别**：一次问询的时机。

**案例 B · 交付了一个"小东西"的人**

另一位新人在第二周发现团队一个内部工具的文档是错的，他花了两天时间验证并修正了文档，还加了一个常见问题的处理步骤。这件事很小，**但在转正评审时被两位同事提到**——因为所有人都被这个文档坑过。

**他的总结**：「不需要做一件大事，做一件所有人都烦但没人去做的小事就够了。」

**案例 C · 试用期走掉的人**

有人在入职第六周发现实际工作内容与面试描述的完全不同（面试说做后端，实际被安排做数据标注加少量脚本）。他犹豫了六周，最后在第八周离开。**后来他说，唯一后悔的是没在第三周就走。**

## 7. 延伸与依据

- 《中华人民共和国劳动合同法》**第十九条** —— 试用期期限的限制、只能约定一次试用期、不得约定试用期的情形
- 《中华人民共和国劳动合同法》**第二十条** —— 试用期工资不得低于本单位相同岗位最低档工资或劳动合同约定工资的百分之八十，并不得低于用人单位所在地的最低工资标准
