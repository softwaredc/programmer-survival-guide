# 术语表

> 本页是纯参考表格，不适用八段结构。
> 收录三卷中出现的所有行话和黑话，给一句人话解释。

## 一、求职与入职

| 术语 | 一句话解释 | 你会在哪遇到 |
|---|---|---|
| **offer** | 公司给你的正式录用通知，写明了岗位、薪资、入职时间 | 拿到Offer 之后 / 谈薪时 |
| **base** | 基本工资，每月固定发的那部分。**这是下一份工作的议价锚点** | 谈薪、看 offer 时 |
| **总包 / package** | 一年能拿到的全部（base + 奖金 + 补贴 + 公积金 + 期权） | 谈薪时 |
| **签字费** | 一次性给的一笔钱，通常用来补偿你跳槽的损失（比如没拿到的年终奖） | 跳槽谈判时 |
| **三方协议** | 学校、你、公司三方签的一份协议，**不是劳动合同** | 应届生入职前，详见[三方协议](../vol1/07-三方协议.md) |
| **应届身份** | 毕业当年（及部分单位认定的一段时间内）可以走校招通道的身份，**认定口径各单位不同** | 校招，非常值钱 |
| **HC（Headcount）** | 招聘名额。一个团队有没有 HC 决定了今年招不招人 | 打听机会时 |
| **背调** | 背景调查，新公司在发 offer 前核实你的任职经历 | 拿 offer 前后，详见[离职交接与背调](../vol3/08-离职交接与背调.md) |
| **ATS** | 企业用来筛选简历的系统，会按关键词过滤 | 投简历时——所以 JD 里的词要出现在简历里 |
| **BD / 内推** | 通过内部员工推荐投递，转化率通常远高于海投 | 找工作时 |

## 二、薪资与股权

| 术语 | 一句话解释 | 你会在哪遇到 |
|---|---|---|
| **13 薪 / 14 薪** | 一年发 13 或 14 个月工资。**本质多数是年终奖的另一种说法** | offer 里 |
| **年终奖** | 年底发的奖金。"2~6 个月"通常意味着实际发 1~2 个月 | 谈薪时、**问往年实际发放情况** |
| **绩效工资** | 薪资中随考核浮动的部分。**占比过高会拉低你的补偿计算基数** | 签合同时 |
| **公积金** | 你和公司各缴一份进入你的账户，**公司那份也是你的钱** | 查工资条时，详见[薪资结构解剖](G2-薪资结构解剖.md) |
| **五险一金** | 五项社会保险 + 住房公积金 | 入职、社保相关流程 |
| **期权（Option）** | 给你一个**按约定价格购买**公司股份的权利。**行权时要掏钱** | offer / 离职时 |
| **RSU** | 限制性股票单位，到归属期**直接给你**股票，不需要掏钱 | 外企、上市公司 offer |
| **行权（Exercise）** | 用约定的价格去买期权对应的股份 | 离职时（窗口期通常很短） |
| **归属 / Vesting** | 期权按时间分批到手的过程（常见四年归属） | 看期权协议时 |
| **Cliff** | 归属的悬崖期，常见的是一年——**满一年才归属第一批** | 看期权协议时 |
| **P / E / M 序列** | 一些公司对职位序列的划分（如 P=专业岗、M=管理岗） | 大厂的职级体系 |

## 三、在职

| 术语 | 一句话解释 | 你会在哪遇到 |
|---|---|---|
| **OKR / KPI** | 两种目标管理方式。OKR 偏挑战性目标，KPI 偏考核指标 | 季度初、季度末 |
| **绩效评级** | 对你一个周期表现的分档（常见的有 S/A/B/C 或达成/部分达成/未达成） | 季末、年末 |
| **360 评估** | 让上下级和同级都给你写评价 | 绩效周期 |
| **PIP** | 绩效改进计划。**收到它通常意味着你已经在被清退的流程里了** | 被约谈时——需高度重视 |
| **盘点** | 管理层对团队人员的评估，通常涉及去留和晋升 | 年末/年中 |
| **1on1** | 你和直属上级的定期一对一沟通 | 每周/每两周 |
| **cr / Code Review** | 代码评审 | 日常 |
| **oncall** | 轮流值班，处理线上问题 | 排班表 |
| **向上管理** | 有意识地让上级了解你的工作与价值（不是拍马屁） | 详见[可替代性自测](../vol2/02-可替代性自测.md) |

## 四、离职与权益

| 术语 | 一句话解释 | 你会在哪遇到 |
|---|---|---|
| **N** | 经济补偿，按工作年限算：每满一年给一个月工资 | 谈离职补偿时 |
| **N+1** | N 加上一个月的**代通知金**（公司没提前 30 天通知时才给） | 谈离职补偿时 |
| **2N** | 违法解除的赔偿金，是 N 的**两倍**，前提是解除违法 | 谈离职补偿时 |
| **经济补偿** | 合法解除时依法支付的补偿（就是上面说的 N） | 《劳动合同法》第 47 条 |
| **赔偿金** | 违法解除时支付的惩罚性赔偿（2N），**与经济补偿不叠加** | 《劳动合同法》第 87 条 |
| **代通知金** | 公司没提前 30 天通知解除时额外付的一个月工资 | 《劳动合同法》第 40 条 |
| **月平均工资** | 解除前十二个月的**应得工资平均**（含奖金、津贴、加班费），**不是你的 base** | 计算补偿时的核心变量 |
| **封顶规则** | 月工资高于当地上年度职工月平均工资 3 倍的，按 3 倍计，且年限最高 12 年 | 高收入者必看 |
| **竞业限制** | 离职后一定期限内不能去竞争对手，**公司必须按月支付经济补偿** | 签合同、离职时 |
| **离职证明** | 公司出具的证明，**不得写入对你的负面评价** | 办离职时 |
| **协商解除** | 双方谈好条件后解除，是最常见的和平分手方式 | 离职时 |
| **违法解除** | 公司没有合法依据地解除你，后果是 2N | 认定需结合具体情形咨询专业人士 |
| **社保断缴** | 社保连续缴纳中断，可能影响医保报销和城市资格（购房/摇号/落户） | 离职后，详见[社保公积金](../vol3/05-社保公积金.md) |
| **灵活就业参保** | 没有单位时以个人身份继续缴纳社保的合法方式 | 失业期间 |
| **失业金 / 失业保险金** | 你在职时缴过的失业保险待遇，**领取它是权利，不影响找工作和养老金** | 失业后第一时间去办 |
| **劳动仲裁** | 劳动争议的法定处理流程，**时效为一年**，且不收费 | 协商不成时 |
| **仲裁时效** | **一年**，从你知道或应当知道权利被侵害之日起算。**最容易错过的一条** | 详见[仲裁与维权](../vol3/09-仲裁与维权.md) |

## 五、其他行话

| 术语 | 一句话解释 |
|---|---|
| **gap** | 两份工作之间的空档期 |
| **跳槽** | 换工作 |
| **降薪 Offer** | 薪资低于上一份的 offer，是否接受要看换来什么 |
| **Counter Offer** | 你提出离职时公司为挽留你而提出的加价条件 |
| **优化 / 毕业** | 被裁的行业委婉说法 |
| **35 岁危机** | 对程序员年龄焦虑的通俗说法。本质上焦虑来自可替代性，不完全来自年龄 |
| **外包** | 由第三方公司派驻到甲方工作，合同关系在第三方 |
| **远程 / 混合办公** | 完全或部分不在办公室工作 |
