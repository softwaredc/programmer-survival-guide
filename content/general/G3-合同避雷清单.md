# 合同与条款避雷清单

## 1. 三十秒自检

- [ ] 你签合同时没有逐条看
- [ ] 你没有留存一份劳动合同
- [ ] 你的工作地点写的是"全国"或"公司指定"
- [ ] 你的薪资结构里 base 很低、绩效占比很高
- [ ] 你签过"已收到合同"之类的空白签收单

打勾 ≥2 个，往下读。**第 5 条在任何情况下都不该发生。**

## 2. 结论先行

**签合同的两条底线：**

1. **一定要拿到属于你的那一份。** 劳动合同文本由用人单位和劳动者**各执一份**，这是明确的法定要求（《劳动合同法》第 16 条）。拿不到副本，争议时你会非常被动。
2. **任何空白都不要签。** 包括空白的合同、以及"最终版以公司为准"的承诺。

然后是下面十类高危条款。**它们的共同特点是：看起来是套话，实际上在转移风险。**

## 4. 可直接抄的话术 / 模板

### 十类高危条款 + 修改建议

---

**① 工作地点写"全国"、"公司指定"、"以公司安排为准"**

- **风险**：公司可以单方面把你调到任何城市，你不去就可能被认定为不服从安排
- **修改请求**：
  > 「工作地点这一栏，方便写明确一点吗？比如 XX 市。
  > 如果需要外派或调动，可以另行约定——但我想把日常的工作地点写清楚。」

---

**② base 极低、绩效工资占比过高**

- **风险**：绩效部分往往由公司单方考核，发生争议时你可能拿不到；更严重的是，**它会拉低你的月平均工资基数**，直接影响经济补偿的计算（见[赔偿金怎么算](../vol3/02-赔偿金怎么算.md)）
- **修改请求**：
  > 「关于薪资结构，我想问一下：绩效部分的考核标准是什么？发放有没有保障？
  > 如果可能，我希望 base 的部分能再高一些。」

---

**③ "公司可根据经营需要调整岗位与薪资"**

- **风险**：这是一个非常宽的单方变更条款。**工作岗位和薪资属于劳动合同的核心内容，变更一般应当协商一致**
- **修改请求**：
  > 「这一条我想商量一下。如果涉及到岗位或薪资的调整，
  > 能否写成'经双方协商一致后调整'？」

---

**④ 加班费写进 base（俗称"包薪制"）**

- **风险**：约定工资包含加班费可能使你的加班费主张难以得到支持。
  **加班费是法定应当另行支付的报酬**
- **修改请求**：
  > 「关于加班的部分，我想确认一下：
  > 工资里是否包含了加班费？如果是的话，能否分开写清楚？」

---

**⑤ 试用期超长，或试用期工资过低**

- **风险**：超出法定期限的部分无效；工资低于法定标准的部分你有权要求补足
- **法定标准**：合同期≥3个月不满1年：试用期≤1个月；≥1年不满3年：≤2个月；≥3年及无固定：≤6个月。**试用期工资不低于本单位相同岗位最低档工资或合同约定工资的 80%，且不低于当地最低工资标准**（《劳动合同法》第 19、20 条）
- **修改请求**：
  > 「我查了一下，《劳动合同法》第十九条写的是 XX（说出你的合同期限对应的上限）。
  > 我们这里的试用期是 XX，想确认一下是不是我理解有出入？」

---

**⑥ 竞业范围过宽、补偿过低、或完全没写补偿**

- **风险**：详见[竞业协议](../vol3/06-竞业协议.md)。核心是：**竞业期间公司应当按月支付经济补偿**
- **修改请求**：
  > 「关于竞业限制，能否把范围写得更具体一些？
  > 另外想确认一下，如果启动的话，每月的经济补偿是多少？」

---

**⑦ 违约金条款（非法定情形）**

- **风险**：**除专项培训服务期和竞业限制两种法定情形外，用人单位不得与劳动者约定由劳动者承担违约金**（《劳动合同法》第 25 条）
- **这是本节里最有用的一条**：很多时候"提前离职要赔 X 万"这类条款本身就可能不成立
- **确认方式**：
  > 「关于违约金的这一条，是否涉及的是专项培训服务期或者竞业限制？
  > 如果是其他情形，我想了解一下具体的依据。」

---

**⑧ 空白合同、不给你副本、让你签空白签收单**

- **风险**：这是所有情形里最严重的一类。**签了空白文件，等于把内容决定权交给了对方**
- **正确做法**：**不要签。** 无需解释，无需商量：
  > 「不好意思，我这边不能签没有填完整的文件。麻烦补齐之后我们再走流程。」

---

**⑨ "员工手册确认书"没读就签**

- **风险**：员工手册里可能包含岗位的变更条款、奖惩制度，签字意味着你已确认知晓
- **正确做法**：
  > 「方便给我一份员工手册看一下吗？我想确认完再签。」

---

**⑩ 离职证明 / 解除协议里的不利表述**

- **风险**：影响后续背调。法定要求解除证明**不得写入**对劳动者不利的主观评价
- **详见**：[别签的东西](../vol3/04-别签的东西.md) 与 [离职交接与背调](../vol3/08-离职交接与背调.md)

---

### 通用修改请求模板（复制使用）

```
您好，

关于合同第 X 条，我想商量一下：
这一条目前的表述是「原文」。
我的顾虑是 XX。
能否修改为「建议的表述」？

我也希望这份合同对双方都是清楚的，这样能避免以后的误会。
```

要点：**永远不要说"这对我不公平"**。说"对双方都清楚"——这是替对方考虑的说法，很难被拒绝。

---

### 签约前检查清单

```
□ 我拿到了属于自己的那一份合同（并且妥善保存）
□ 工作地点写明了具体城市
□ base 和绩效的比例是明确的，且 base 占比合理
□ 没有"公司可单方调整岗位和薪资"的宽泛条款
□ 加班费没有打包进 base
□ 试用期长度符合法定上限，工资不低于法定标准
□ 违约金条款只涉及法定情形（专项培训 / 竞业）
□ 竞业条款（如有）写明了范围、期限、补偿金额
□ 我没有签任何空白文件或空白签收单
□ 员工手册我读过再签的确认书
```

## 5. 五个常见错误

1. **签完就没再看、也没留副本**
   → 后果：几年后发生争议时，你连合同条款都记不清，也没有凭据
   → 正确做法：**签约当天拍照或扫描存档**

2. **觉得"这些都是标准模板，改不了"**
   → 后果：这是最大的一个误解。**绝大多数条款是可以商量的**，尤其是 offer 阶段
   → 正确做法：**问一句的成本是零。** 最坏的结果是对方说"不行"，那时你再签也不迟

3. **签了含糊/空白条款**
   → 后果：本节最严重的一类
   → 正确做法：**拒绝。这个不需要商量**

4. **以为签了就不能改**
   → 后果：已经签了有问题的条款就自认倒霉
   → 正确做法：**合同变更也可以协商**。而且部分明显违法的条款本身就可能不具有约束力。**不确定时咨询专业人士**

5. **为了拿到 offer 而接受所有条款**
   → 后果：在薪资上谈赢了，在条款上输掉更多
   → 正确做法：**条款和薪资是一样重要的谈判内容**

## 6. 真实案例（脱敏）

**案例 A · 因为多问了一句**

某工程师在签合同前逐条看，发现base 只占总薪资的 50%，其余是绩效。他按上面的话术问了一句，HR 调整到了 70%。**一年后他被裁员时，这个改动直接影响了经济补偿的计算基数——差异接近两个月工资。**

**做对了**：花十分钟看条款，省下了几个月的钱。

**案例 B · 空白签收单的代价**

有人入职时被要求签一张"已收到劳动合同"的签收单，当时合同还没给他。半年后发生争议，公司拿出了一份合同，里面有他没有意识到的条款。**虽然最终争议通过其他途径解决了，但过程极其被动。**

**教训**：**空白文件零容忍。**

**案例 C · "提前离职赔 X 万"**

某工程师的合同里有一条"服务期不满 X 年离职需赔偿 X 万元"。他没有接受过公司出资的专项技术培训。**按照法律规定，除专项培训服务期和竞业限制外，用人单位不得与劳动者约定由劳动者承担违约金。** 他咨询后据此沟通，最终该条款没有被执行。

（注意：**这只是一个通用说明，具体是否适用必须结合事实咨询专业人士**。）
