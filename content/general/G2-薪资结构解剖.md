# 薪资结构解剖：钱到底怎么组成

## 1. 三十秒自检

- [ ] 你说不清自己一年到底挣多少
- [ ] 你不知道公积金算不算收入
- [ ] 你分不清 13 薪和年终奖
- [ ] 你不知道期权和 RSU 的区别
- [ ] 你对"税"的了解只有"公司会扣"

打勾 ≥2 个，往下读。**第一条非常常见：很多人工作了五年，仍然不知道自己的年总收入是多少。**

## 2. 结论先行

**一封信里的钱通常由这些部分组成：**

| 组成部分 | 说明 | 确定性 |
|---|---|---|
| **base（基本工资）** | 每月固定发放的部分。**它是下一份工作的议价锚点** | 最高 |
| 岗位/绩效工资 | 可能随考核浮动 | 中 |
| 补贴（餐补/交通/住房） | 通常固定或按实际报销 | 高 |
| 加班费 | 依法应支付（见 [劳动法速查](G1-劳动法速查.md)） | 视约定 |
| **年终奖 / 13薪 / 14薪** | 差别巨大，见下文 | **低** |
| **期权 / RSU** | 见下文 | **最低** |
| **公积金** | **公司是替你存的钱，**个人 + 公司**两份都是你的** | 高 |
| 签字费 | 一次性，常见于跳槽补偿 | 中高 |

**三个最容易被忽略的事实：**

1. **公积金是实打实的收入。** 员工缴一份、公司缴一份，都进入你的账户。**算年收入时必须算上公司那一份。**
2. **"13 薪"多数就是年终奖的一种说法。** 不要把它当成额外的惊喜。
3. **base 是最重要的那个数字。** 因为下一份工作的涨薪幅度通常基于你上一份的 base 来谈。

## 3. 现在就做

| 时间窗 | 动作 |
|---|---|
| **今天** | 打开工资条/银行流水，把自己过去 12 个月的**所有**入账汇总（这是你的真实年收入） |
| **今天** | 查你的公积金缴存基数和比例（政务 APP 或公积金中心可查），算出公司那份是多少 |
| **本周** | 搞清楚你的年终奖到底是"固定几薪"还是"浮动区间"——问往年的实际发放情况 |
| **本周** | 用[真实时薪计算器](../../tools/real-hourly-wage/index.html)算出你的真实年收入与时薪 |
| **本月** | 做一次个税年度汇算（如果你还没做过） |

## 4. 可直接抄的话术 / 模板

**场景一：确认薪资构成（面试/入职时必问的一套问题）**

```
您好，想确认一下薪资的构成：

1. base 是多少？一年发几个月？
2. 年终奖的部分——是固定的（几薪），还是浮动区间？
   如果是浮动的，往年实际大概发多少？
3. 公积金的缴纳基数和比例分别是多少？（按实际工资缴，还是有上限？）
4. 有没有餐补/交通补/住房补贴？金额和发放方式？
5. 试用期薪资是否打折？打折多少？试用期多久？
6. 期权/RSU：如果有，归属节奏是怎样的（几年、有没有 cliff）？
```

要点：**这六个问题在 offer 阶段问完全正常，而且显得你专业。** 如果对方含糊其辞，这本身就是信息。

**场景二：被问"你现在薪资是多少"**

> 「我目前的年总包大概是 XX（含奖金和公积金）。
> 我这次的期望是 XX。」

要点：**说清楚口径。** "月薪 XX"和"年总包 XX"差别很大。**同时，永远给对方的期望值高于你的现状。**

**场景三：争取更高的公积金缴纳基数**

> 「想问一下公积金的缴纳基数，是按实际工资还是按某个上限？
> 如果可以按实际缴纳，我想确认一下。」

要点：**公积金是少数几项"公司多缴、你也多得"的东西**，而且在很多城市用于租房或购房。**问一句的成本为零。**

### 期权 vs RSU：一句话区别

| | 期权（Option） | RSU（限制性股票单位） |
|---|---|---|
| 本质 | **买的**权利（按约定的行权价） | **直接给**的股票（到归属期自动给你） |
| 你需要掏钱吗 | **要**（行权时要按行权价付款） | **不要**（归属时就属于你） |
| 离职后 | 未行权的通常有很短的行权窗口 | 未归属部分通常作废 |
| 税务时点 | 行权时可能产生纳税义务 | 归属时通常产生纳税义务 |

> ⚠️ **税务规则复杂且会因政策调整而变化。涉及金额较大时请咨询税务专业人士。**
> 详见 [期权与未行权](../vol3/07-期权与未行权.md)。

## 5. 五个常见错误

1. **把公积金不当钱**
   → 后果：低估自己 10%~24% 的收入，谈薪时被低报
   → 正确做法：**算总包时把公司缴纳的那一半也算进去**

2. **相信"年终奖 2~6 个月"的承诺**
   → 后果：入职后发现常年发 1 个月
   → 正确做法：**问"往年实际发了多少"**。区间通常等于最低值加一点点

3. **把期权按名义现值算进收入**
   → 后果：把一张概率很低的彩票当成确定的工资
   → 正确做法：**做决策时按 0 算**（详见 [Offer 选择](../vol1/06-offer选择.md)）

4. **只谈月薪不谈总包**
   → 后果：月薪涨了，但年终比例下调、公积金基数低，实际年收入反而下降
   → 正确做法：**每次谈薪都按"年总包"谈**

5. **不知道自己适合哪种计税方式**
   → 后果：可能多缴税
   → 正确做法：**每年做一次个税年度汇算**（个税 APP 上几分钟就能完成），系统会算出你是否需要退税。**注意：年终奖的计税方式曾经有特殊政策，以最新规定为准**

## 6. 真实案例（脱敏）

**案例 A · 公积金的差别**

两个 offer 月薪都是 20K：
- A 公司公积金按 20K 的 12% 缴纳 → 个人 2400 + 公司 2400 = **每月 4800** 进你的账户
- B 公司按当地最低基数缴纳 → 每月可能只有几百元

**一年下来，这个差别可能超过 5 万元。** 而很多人在比较 offer 时完全没看这一项。

**案例 B · "13 薪"的真相**

有人入职时被告知"我们是 14 薪"，理解为"年底多发两个月"。结果第一年年底发了全额一个月，理由是"绩效达标才发两个月"。**他没有问清楚口径。**

**教训**：问"往年实际发了多少个月"，比听"几薪"有用得多。

**案例 C · 算总包才发现降薪**

有人从 A 跳到 B，月薪从 25K 涨到 28K（+12%），很高兴。后来算总包发现：A 的公积金按全额缴、有餐补、年终固定 3 个月；B 的公积金按最低基数、无补贴、年终 1 个月浮动。**实际年收入反而下降。**

**他后来总结**：「我当时只比较了那一个数字。」
