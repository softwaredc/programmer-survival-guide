## 2. 结论先行

**四条筛选求助渠道的原则：**

1. **优先官方渠道** —— 政务热线、法律援助中心、仲裁委员会。它们免费且信息与时效性最高。
2. **警惕收费的"维权专家"** —— 网上有大量自称"专业维权""包拿 N+1"的账号。**先问清楚是否收费、资质是什么。**
3. **号码以官方最新公布为准** —— 本页只列全国通用且长期稳定的号码，地方号码请你自己在官网查（方法见下）。
4. **不要等到情况严重才求助** —— 尤其是涉及身心健康的时候。

**场景一：拨打政务热线的开场白（通用模板）**

> 「您好，我想咨询一个问题。
> （一句话说清事实：什么时候、发生了什么、涉及什么）
> 想请问：这种情况我应该找哪个部门？需要准备什么材料？」

要点：**先说事实，再问流程。** 接线员每天接很多电话，清晰的事实陈述能让他们更快给出有效答复。

**场景二：现场咨询前的准备清单（去窗口前先看）**

```
□ 一段话写清事实（时间线：什么时候入职、发生了什么、目前进展）
□ 身份证
□ 劳动合同（原件 + 复印件）
□ 相关书面材料（解除通知、邮件、聊天记录导出的纸质版）
□ 一张纸一支笔（记录答复内容，以及对方告知的下一步）
```

要点：**带齐材料再去。** 很多问题只有看到具体材料才能给出准确答复。

**场景三：判断网上的"维权专家"是否可信**

```
□ 是否明确说明了收费方式和金额？（不说明 = 危险信号）
□ 是否承诺了具体结果？（"包拿 2N""一定赢" = 危险信号，没人能承诺结果）
□ 是否有可查的资质？（执业律师可以在当地司法局官网查到）
□ 是否要求你先付大额费用？（先付费后服务要格外谨慎）
□ 是否要求你把账号密码/验证码交给他们？（**任何情况下都不要**）
```

要点：**正规的执业律师可以查到执业证号。** 这是最简单的验证方式。

**场景四：涉及身心健康时的自我表达模板（打电话/面诊开场）**

> 「您好，我想预约咨询。
> 我最近因为工作变动，情绪和睡眠持续不太好，已经有两周以上了。
> 我不确定这算什么情况，想请专业人士帮我看一下。」

要点：**你不需要先给自己下结论才配去求助。** "我不确定，想请你看看"是最正确、也是最轻松的开场。

## 5. 五个常见错误

1. **在网上随便找一个"维权专家"**
   → 后果：付费后没有实质帮助，甚至被诱导做出损害自身利益的决策
   → 正确做法：**先用免费的官方渠道（12348 / 12333）确认基本情况**，再决定是否需要聘请律师

2. **相信"包赢""包拿 2N"的承诺**
   → 后果：这是最典型的危险信号。**没有任何人能承诺法律结果**
   → 正确做法：**凡是承诺结果的，一律远离**

3. **只看网上的过时信息**
   → 后果：找到的号码已经停用、政策已经变更
   → 正确做法：**以官方网站的最新公布为准**。本页也因此不列具体地方号码

4. **碍于面子不求助**
   → 后果：小问题拖成大问题，尤其是涉及身心健康时
   → 正确做法：**求助是处理问题，不是承认失败。** 政务热线咨询是完全匿名的

5. **咨询后不做记录**
   → 后果：三个渠道给了三个不同说法，你记不清谁说了什么
   → 正确做法：**当场记录：日期、渠道、答复要点、下一步建议**

## 6. 真实案例（脱敏）

**背景**：某人遇到补偿纠纷，第一反应是在网上搜「劳动仲裁」，结果找到一堆号码和自称「专业维权」的账号。

**做对了什么**：他先拨了 12348（公共法律服务热线），免费咨询后才知道自己的情况距离时效只剩两个月——这一通电话的价值远超预期。

**做错了什么**：他差点先联系了一个承诺「包拿 2N」的付费账号。

**结果**：通过官方渠道了解了基本流程与自己的处境，之后才决定是否需要聘请律师。

**如果重来**：第一步就用官方渠道。不花一分钱，还能校准自己的判断。

### 关于本页的设计原则

本页的每一条渠道都遵循一个原则：**告诉你"怎么找到它"，而不是"号码是多少"。**

这样做的原因是：

- 地方热线号码会变更
- 网络上的号码有可能是过时的或虚假的
- 官方网站是唯一可靠的信息源

**唯一例外**：**12333** 和 **12348** 是全国通用的政务热线，长期稳定，因此本页直接列出。
