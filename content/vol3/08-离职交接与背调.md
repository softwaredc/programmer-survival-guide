# 离职交接与证明：离职证明 / 背景调查会查什么

## 1. 三十秒自检

- [ ] 你不确定交接该交哪些东西、要不要写文档
- [ ] 你不知道离职证明上会写什么、能不能改
- [ ] 你担心前一家公司在背调时说你坏话
- [ ] 你没有提前维护好可以做证明人的同事
- [ ] 你在考虑"留一手"，比如保留某些文档或账号

打勾 ≥2 个，往下读。**特别是第 5 个——那一节可能会帮你避开一个真实的坑。**

## 2. 结论先行

**交接的三条原则：**

1. **交清楚。** 交接质量直接影响你在行业里的口碑，而这个圈子比你以为的小。
2. **书面化。** 口头交接等于没有交接，事后出问题说不清。
3. **留好人。** 你的证明人比你的简历重要——一份好背调能救一份平淡的简历，一份坏背调能毁掉一次完美的面试。

**关于背调，程序员最需要知道的是**：绝大多数正规公司的背景调查**只核实客观事实**——任职时间、职位、汇报关系、离职原因（是主动还是被动）、有无违纪记录。主观评价通常不在核实范围内，因为对方也要规避法律风险。

**关于离职证明**：用人单位出具的解除或终止劳动合同证明，应当写明劳动合同期限、解除或者终止的日期、工作岗位、在本单位工作年限。**不得写入对劳动者不利的主观评价。**

## 3. 现在就做

| 时间窗 | 动作 |
|---|---|
| **今天** | 列出完整的交接清单（见第 4 段模板），发给接手人和主管，**并抄送自己** |
| **今天** | 向 2~3 位关系好的同事/上级发出"证明人"邀约（见第 4 段话术） |
| **本周** | 完成书面交接文档，包含：系统权限清单、代码仓库位置、文档索引、未完成事项、关键联系人 |
| **本周** | 归还设备、注销个人账号与公司账号的绑定、退出所有公司相关的群和平台 |
| **最后一天前** | 确认拿到离职证明，并**当场检查上面写的内容** |
| **本月** | 保存好离职证明、社保记录、个税记录（未来入职可能需要） |

## 4. 可直接抄的话术 / 模板

### 交接清单模板（复制使用）

- [ ] 生产服务器 / 跳板机：____（已下线我的密钥）
- [ ] 第三方平台（云、监控、日志、CI）：____（已移交管理员）

## 三、进行中的事项
- [ ] 事项 A：负责人 ____ / 当前状态 ____ / 下一步 ____

**场景一：向同事请求做你的证明人（提前说，不要临时找）**

> 「我要离开这边了，接下来找工作。想问一下，如果新公司那边做背景调查打给你，
> 你方便帮我确认一下我的任职时间和岗位吗？
> 如果你觉得不方便也没关系，完全理解。」

要点：**先给对方拒绝的空间。** 愿意的人才值得用。同时问清楚对方的准确职务和联系方式，方便你在背调表上填写。

**场景二：和主管谈交接**

> 「我想在最后这段时间把交接做扎实一点。我列了个清单，你看下有没有遗漏的？
> 特别是那些你担心只有我知道的东西，我想重点写一下。」

要点：这句话的价值在于——**它把主管从"监督者"变成"共同完成者"**。多数主管听到这句话后会明显态度变好，而这份好感会延续到他接到背调电话的时候。

**场景三：拿到离职证明时当场检查**

> 「麻烦我看一下这份证明。」

当场核对四项：入职离职日期、岗位、工作年限、**有无负面表述**。
如有负面或不实内容，当场提出：

> 「这里的离职原因写的是 XX，和我了解的情况不太一致。
> 按《劳动合同法实施条例》第二十四条，离职证明应该只写客观信息。
> 方便改成'协商一致解除劳动合同'吗？」

**场景四：如果被问到"这个人为什么离职"——你如何说服前东家保持客观**

> 这个你控制不了。但你可以做的是：**在离开之前，让主管知道你会如何描述这次离职。**

> 「关于这次的事，我对外统一的说法是'团队调整，协商一致离职'。
> 如果有人来问，我也会这样讲，不会说任何负面的话。
> 希望我们这边也是一致的。」

要点：**互相确认口径，是保护双方的最优解。** 这句话对直属上级尤其有效——他通常也不想背上一个"赶人走"的名声。

## 5. 五个常见错误

1. **交接草草了事**
   → 后果：圈子很小，你的交接质量会成为你的声誉。下一次面试时，对面可能坐着你前同事的朋友
   → 正确做法：把最后两周当作一次"产品发布"来做——文档、清单、当面说明，一样都不少

2. **没有书面交接记录**
   → 后果：后续线上出问题时，矛头容易指向已经离开的你，而你拿不出证据说明已交接清楚
   → 正确做法：**交接文档发邮件，抄送自己留存**。这一份邮件在未来可能救你一次

3. **忘了维护证明人**
   → 后果：背调时对方联系不上人，或者联系到关系一般的人，得到一个平淡甚至负面的评价
   → 正确做法：**离职前一周内**主动邀约 2~3 位证明人，最好包含一位直属上级和一位平级同事

4. **在离职证明上吃了亏**
   → 后果：拿到一份写了负面评价的证明，影响后续入职
   → 正确做法：**当场检查**。法律明确规定离职证明不得写入不利内容，发现问题当场要求更正

5. **"留一手"——私存代码、文档、或保留后门账号**
   → 后果：这是本节能给的最严肃的警告。可能构成侵犯商业秘密或违反保密义务；情节严重时可能涉及刑事责任。而且，**在这个行业里一旦传开，代价远超收益**
   → 正确做法：**只保留你自己的东西**——你自己写的总结、个人作品、公开分享过的技术文章。代码、业务文档、客户数据、内部资料，一律不留

## 6. 真实案例（脱敏）

**背景**：某 SaaS 公司，后端工程师，因团队调整离职。

**做对了什么**：他花了整整一周写交接文档，把三个核心模块的架构、部署方式、常见故障处理都写成手册，还录了两段屏幕演示。最后一天主管在群里公开感谢了他。半年后他面试的一家公司，HR 做背调时联系到了这位主管——评价非常好，直接通过了原本有些犹豫的用人决策。

**做错了什么**：他没有提前和同事确认能不能做证明人，背调时 HR 联系的是他关系一般的另一位同事，拿到了一个"挺好的，没什么特别的"的评价。虽然不影响结果，但浪费了一次有力的推荐机会。

**结果**：入职顺利。**教训是：交接做得好，能变成资产；证明人没提前约，等于随机抽奖。**

另一个反例（脱敏）：有人离职时悄悄保留了公司的客户名单，打算自己接私活用。被前东家发现后发了律师函，虽然没有走到诉讼，但这个事在同行的圈子里传开了，后续求职受到明显影响。

## 7. 延伸与依据

- 《中华人民共和国劳动合同法》**第五十条** —— 用人单位应当在解除或终止劳动合同时出具证明，并在十五日内办理档案和社会保险关系转移手续
- 《中华人民共和国劳动合同法实施条例》**第二十四条** —— 解除或终止劳动合同的证明应当写明劳动合同期限、解除或终止的日期、工作岗位、在本单位工作年限；不得写入对劳动者不利的主观评价
