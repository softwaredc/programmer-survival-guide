# 别签的东西：离职协议里那些要命的条款

## 1. 三十秒自检

- [ ] 协议里有"双方再无其他争议"之类的一句话
- [ ] 协议没写清楚补偿金额和支付时间
- [ ] 协议里出现了竞业限制条款
- [ ] 社保缴纳截止月份没写，或者写得不明确
- [ ] 离职原因的表述不是"协商一致解除"
- [ ] 对方让你签空白文件，或者说"内容后面补"

打勾 ≥2 个，**先别签**。打勾第 6 个，**立刻停止签字**。

## 2. 结论先行

离职协议上真正危险的不是金额那一栏——金额是明的，算错了还能争。**真正要命的是那些看起来是套话的条款。**

必须逐条检查的七项：

1. 补偿金额是否**确定**（不能写"按公司规定"）
2. 支付时间是否**明确**（具体到日期或期限）
3. 社保与公积金缴纳到哪个月
4. "双方再无争议"这类兜底条款的范围
5. 竞业是否被启动、范围多大、补偿多少
6. 年假、加班费如何结算
7. 离职原因怎么写（影响你下一份工作的背调）

**黄金规则：只要有一项是空白、含糊或你不理解的，就不要签。**

## 4. 可直接抄的话术 / 模板

### 条款检查清单（复制使用）

```
□ 1. 补偿金额：明确写金额数字，不写"按公司政策"
□ 2. 支付时间：明确到 X 年 X 月 X 日前，或"离职后 N 个工作日内"
□ 3. 社保公积金：明确写"缴纳至 YYYY 年 MM 月"
□ 4. 年假折算：未休年假 X 天，折现 XX 元
□ 5. 加班费：如有未结算加班，明确金额或写明"已全部结清"
□ 6. 最后工作日：YYYY-MM-DD
□ 7. 离职原因：协商解除 / 劳动合同期满 / 其他（不能是负面表述）
□ 8. 竞业：明确写"不启动"或写明范围+期限+补偿金额
□ 9. 兜底条款：如"双方再无争议"，确认前面所有钱已到账或已写明
□ 10. 协议份数：一式两份，本人留存一份
```

**场景一：要求把含糊表述改成明确的**

> 「这一条写的是'按公司相关规定执行'，我不太确定具体是多少。
> 方便写清楚具体金额和支付时间吗？我也是为了双方都清楚，避免后面再沟通。」

要点：**永远不要说"我不信任你们"**。说"避免后面再沟通"——这是替对方考虑的姿态，对方很难拒绝。

**场景二：关于"双方再无争议"兜底条款**

> 「这一条我理解是标准条款。不过我希望明确一下：它覆盖的范围是不是仅限于这次的补偿金额？
> 如果方便，能否写成'除本协议约定的补偿款项外，双方就劳动关系的解除不存在其他争议'？」

要点：兜底条款本身常见且正常，**关键是它的范围**。限定范围的表述是完全合理的请求。

**场景三：关于竞业限制**

> 「关于竞业限制，我需要一个书面确认：公司这次是否对我启动竞业限制？
> 如果启动，请写明限制范围、期限和每月补偿金额；如果不启动，请写明'不予启动'。
> 这一条对我找下一份工作非常关键，麻烦您了。」

要点：**最重要的一句话是"书面确认"。** 口头说"不会启动"没有任何意义，因为公司可以在你入职新东家后反悔。参见[竞业协议](06-竞业协议.md)。

**场景四：对方让你签空白文件或"内容后补"**

> 「不好意思，我这边不能签没有填完整的文件。
> 麻烦把内容补齐之后我们再走流程，我可以等。」

要点：**不要解释更多。** 这一条没有任何商量余地，也不需要任何解释。对方如果坚持，这件事本身就是强烈的危险信号。

**场景五：离职证明的离职原因**

> 「离职证明上的离职原因，希望能写'协商一致解除劳动合同'或者客观的表述。
> 这一份证明我找下一份工作时要提供给背调方。」

要点：离职证明应当载明劳动合同期限、解除或终止日期、工作岗位、在本单位工作年限。用人单位**不得**在离职证明中写入对劳动者不利的主观评价。

## 5. 五个常见错误

1. **在钱到账之前签了含"再无争议"的协议**
   → 后果：协议签了、钱没到账、争议已被声明不存在，追讨路径被自己堵死
   → 正确做法：**钱到账再签**，或在协议里写明"于 X 日前支付，逾期本协议关于放弃权利的部分不生效"

2. **接受"我们口头答应你"的补充条款**
   → 后果：所有没写进协议的承诺，在人事变动、主管离职后会蒸发得无影无踪
   → 正确做法：**任何对方承诺的东西，必须写进协议或至少书面确认邮件**

3. **没注意到协议里夹带了竞业启动条款**
   → 后果：签完之后才发现自己被限制，而且通常拿不到足额补偿
   → 正确做法：从头到尾读一遍再签（不是扫一眼）。**签之前先问"竞业是否启动"**

4. **签了没留一份**
   → 后果：事后争议时你手上没有协议原件
   → 正确做法：协议一式两份是常规做法，**你有权留存一份**。拿到后拍照存档

5. **为了"赶紧结束这件事"而跳读**
   → 后果：这是最常见的情况。人在疲惫和压力下会跳过细节，而坑全在细节里
   → 正确做法：把协议带回家，**第二天早上再读一遍**。一夜之间没有坏人，只有更清醒的你

## 6. 真实案例（脱敏）

**背景**：某在线教育公司，后端工程师，工龄 2 年 8 个月。协议金额谈妥为 N+1，双方都满意。

**做对了什么**：他把协议带回家读，发现最后的"其他约定"里夹了一句「乙方同意公司可视情况启动竞业限制」，没有任何补偿约定。他第二天要求删除这句，HR 说"这是模板，不影响"，他坚持删除，最终改成「本协议不涉及竞业限制」。半年后他入职一家同行公司——如果当时那句话还在，对方完全可以据此向他主张违约。

**做错了什么**：他为了不影响气氛，在另外两个小条款上让步了（年假折算和社保截止月份都没写死），后来多花了三周才把社保的事解决。

**结果**：总金额没变，但那句删掉的话，价值可能远超他拿到的全部补偿。

**如果重来**：读的时候就明白——**金额是这一次的钱，条款是未来的风险，后者通常更贵。**
