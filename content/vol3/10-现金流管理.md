# 现金流管理：你能撑几个月，什么时候该降低预期

## 1. 三十秒自检

- [ ] 你不知道自己的钱还能撑多久
- [ ] 你在用"大概够花"来判断自己的处境
- [ ] 你还没领取失业保险金
- [ ] 你在考虑用投资、借贷或者"先试试看"来解决燃眉之急
- [ ] 你已经开始考虑要不要接受一个明显更低的 offer

打勾 ≥2 个，往下读。**如果你不知道自己能撑几个月，你后面所有的决策都是在瞎猜。**

## 2. 结论先行

**失业期的第一件事不是改简历，是算清楚一个数字：你还能撑几个月（月数 = 可用现金 ÷ 每月必要支出）。**

这个数字之所以重要，是因为**它直接决定了你该采取什么策略**：

| 能撑的时间 | 策略 |
|---|---|
| **≥ 12 个月** | 可以挑，不要急着接第一个 offer。保持节奏，认真准备目标公司 |
| **6~12 个月** | 有选择空间，但要有 timeline。第 3 个月还没进展就调整方向 |
| **3~6 个月** | 双线并行：继续找理想岗位，同时准备一个保底选项（含接受降薪的准备） |
| **< 3 个月** | **优先止血**。先接住现金流（哪怕是过渡性工作），再谈理想 |

**最危险的状态是不知道自己在哪一档。** 因为不知道的人，通常会在第 4 个月突然发现钱不够了，然后在恐慌中做出最差的决定。

**降低预期不是失败，是策略。** 但**在什么时候降**，比**要不要降**重要得多——降得太早浪费了本可以争取的时间，降得太晚会在现金流枯竭时被迫接受任何条件。

## 3. 现在就做

| 时间窗 | 动作 |
|---|---|
| **今天** | 用下面的模板算出"能撑几个月"，**写下来，放在你每天能看到的地方** |
| **今天** | 盘点该拿的钱：失业保险金（先办这个）、未休年假折算、离职补偿款到账情况 |
| **今天** | 把支出分成三类：刚性（房租、社保、吃饭）、可协商（保险、会员、订阅）、可砍（非必要消费）。**当天砍掉第三类** |
| **本周** | 确认社保接续方案（见[社保公积金](05-社保公积金.md)），别让医保断了 |
| **本周** | 设定两个时间点：**警戒点**（剩余 6 个月，开始准备保底选项）和**决策点**（剩余 3 个月，降低接受标准） |
| **本月** | 如果现金流 < 6 个月，认真评估过渡性的收入来源 |

## 4. 可直接抄的话术 / 模板

**场景一：和家人说明现状（很多人最难开口的一段）**

> 「我这边工作有些变动，公司这边团队调整，我离开了。
> 补偿款会到账，失业金我也会去申领，我算了一下家里的钱大概能撑 X 个月。
> 这段时间我打算这样安排：（说你的计划，比如每天投递多少、在做哪些准备）
> 如果到 X 月还没有结果，我会考虑先接受一个过渡性的机会。**不会影响家里的正常开销。**」

要点：**给一个计划和一个时间点，比给一句"别担心"有用一百倍。** 家人的焦虑大多来自未知，有了计划就有掌控感。

**场景二：和房东/银行沟通（提前沟通远好于逾期）**

> 「您好，我这边工作有些变动，想提前和您沟通一下。
> 接下来的房租我可以正常支付，但想了解一下如果遇到暂时的困难，我们这边有什么灵活的安排吗？」

要点：**在还能付的时候沟通，比已经付不出的时候沟通，结果完全不同。**

**场景三：面试时被问到薪资期望（现金流紧张时也别慌）**

> 「我的期望是基于岗位本身和市场水平来的，同时也看整体的机会成本。
> 方便先了解一下这个岗位的薪资区间吗？」

要点：**不要主动降价。** 即便你现金流紧张。原因见第 5 段第 3 条。

**场景四：拒绝一个明显低于自己底线的 offer**

> 「非常感谢你们的时间，我也很认可这个团队的方向。
> 不过薪资和目前的区间差距比较大，我这边暂时没办法接受。
> 希望以后还有合作的机会。」

要点：**体面地拒绝，留下门。** 三个月后你可能确实需要他们。

## 5. 五个常见错误

1. **不肯算那个数字**
   → 后果：这是最常见也最要命的。因为害怕结果而回避计算，导致在毫无准备的情况下被现金短缺击中
   → 正确做法：**今天就算。** 数字越大你越安心，数字越小你越早有准备。**回避它不会让它变好**

2. **为了面子硬撑不降低预期**
   → 后果：耗尽现金后被迫接受远比当初更差的选项，而且那时的谈判地位更弱
   → 正确做法：**提前设定决策点并遵守它**。在决策点之前降预期是策略，之后是被动

3. **主动透露出自己的现金压力**
   → 后果：对方会在 offer 上直接反映你所透露的紧迫感。这在谈判中是最致命的自我暴露
   → 正确做法：无论现金流多紧张，**对雇主、对猎头、对前同事都保持同样的姿态**："我在认真选择合适的机会"

4. **用高风险的"解法"自救**
   → 后果：借贷、加杠杆投资、把所有钱押在一个"机会"上——这些会把一次可承受的失业变成一次财务灾难
   → 正确做法：**失业期的财务原则只有一条：保住本金。** 任何承诺高回报的东西，在你需要用钱的时候都是陷阱

5. **领失业金觉得丢人**
   → 后果：放弃一笔你在职期间已经缴过的、合法的、可以缓解现金流压力的待遇
   → 正确做法：失业保险是你和公司共同缴纳的保险待遇，**领取它是行使权利**。它不影响找工作、不影响背调、无关面子

## 6. 真实案例（脱敏）

**背景**：某后端工程师，工龄 6 年，补偿款到手约 30 万，房贷 1.2 万/月。

**做对了什么**：他在离职第 3 天就算清了"能撑 11 个月"，并且把这个数字告诉了妻子。两人据此决定：前 4 个月只投目标公司，第 5 个月起同步看备选。他在第 6 个月拿到了一个理想岗位的 offer。**全程没有降低过薪资预期，因为他知道自己的时间轴。**

**做错了什么**：前两个月他不好意思申领失业金，也拖着没办社保接续，导致多付了两个月的自缴费用。

**如果重来**：失业金是**第一个就去办**的事。

另一个反向案例（脱敏）：一位工程师没有算过这笔账，一直"感觉钱还够"，到第 5 个月发现余额见底，在恐慌中接了一个薪资低 40% 且发展更差的岗位。**三个月后收到一个原本很想要的机会，但已经错过了。** 差别只在于：前者知道自己的时间轴，后者不知道。
