# 竞业协议：什么时候生效、怎么谈、要不要钱

## 1. 三十秒自检

- [ ] 你入职时签过一份竞业协议，但不记得具体内容
- [ ] 你不确定这次离职公司会不会"启动"竞业
- [ ] 你下一份工作可能在同一行业
- [ ] HR 口头说"不会启动"，但没写进文件
- [ ] 你不知道竞业期间对方该给你多少钱

打勾 ≥2 个，往下读。**这一节的结论可能会节省你半年的职业生涯。**

## 2. 结论先行

关于竞业，程序员最需要知道的四件事：

1. **签了竞业协议 ≠ 竞业生效。** 很多公司的做法是"全员签署、按需启动"。有没有启动，是离职时要书面确认的关键问题。
2. **竞业限制期间，公司必须按月支付经济补偿。** 未支付补偿的，劳动者可以主张不受竞业限制约束（实践中各地口径存在差异，需以当地为准）。
3. **期限上限是二年。** 超过部分不生效。
4. **适用人员有范围限制。** 竞业限制的人员限于用人单位的高级管理人员、高级技术人员和其他负有保密义务的人员。普通基层岗位通常不属于此列。

**最重要的一句话**：口头说"不会启动"没有任何价值。**必须拿到书面确认。**

## 3. 现在就做

| 时间窗 | 动作 |
|---|---|
| **今天** | 翻出入职时签的所有文件，看是否存在竞业协议或包含竞业条款的附件（**很多人签了却不记得**） |
| **今天** | 向 HR 发邮件，**书面确认本次是否启动竞业**（模板见第 4 段） |
| **本周** | 如果启动：确认三件事——限制范围（哪些公司、哪些岗位）、期限（≤2 年）、**每月补偿金额** |
| **本周** | 如果启动但给的补偿过低：尝试谈判限缩范围或提高补偿（见第 4 段话术三） |
| **本月** | 如果书面确认不启动：**把这份邮件/文件妥善保存**，这是你未来最重要的护身符 |
| **求职期间** | 入职新东家前，如实评估新岗位是否落入竞业范围；不确定时考虑咨询专业人士 |

## 4. 可直接抄的话术 / 模板

**场景一：要求书面确认是否启动（最重要的一段）**

```
主题：关于离职后竞业限制事项的确认

XX 您好，

关于竞业限制，我需要一个书面确认以便安排后续的职业规划，麻烦您帮我答复：

1. 公司是否对我启动竞业限制？
2. 若启动：限制的范围、期限，以及每月的经济补偿金额分别是多少？
3. 若不启动：是否可以在离职协议或解除协议中写明「双方确认不启动竞业限制」？

这一项对我接下来的求职非常关键，感谢您的帮助！

XXX
```

要点：**不要接受"应该不会吧"这种回答。** 也不要接受口头答复。要的是书面。

**场景二：离职协议里加上一句**

> 「双方确认，劳动关系解除后，公司不对乙方启动竞业限制，乙方无需履行竞业限制义务。」

要点：这是最干净的处理方式。**一句话，省掉未来所有的麻烦。** 多数情况下 HR 会同意，因为对他来说这只是确认事实。

**场景三：如果公司要启动，谈缩小范围和提高补偿**

> 「我理解公司启动竞业限制的考虑。
> 关于具体条款，我有两点想商量：
> 一是范围，能否把限制明确限定在直接竞争对手的具体名单内，而不是整个行业？
> 二是补偿标准，目前这个金额和我履行义务期间的实际影响差距比较大，能否调整？
> 我希望能找到一个双方都能接受的方式。」

要点：**谈判方向是"限缩范围 + 提高补偿"，而不是"我不签"。** 后者通常会让关系恶化且往往不可行。

**场景四：如果公司没有支付补偿**

> 「我想确认一下竞业限制补偿的发放安排。
> 按我的理解，竞业限制期间公司应当按月支付经济补偿。
> 如果公司决定不支付，我理解竞业限制对我不产生约束力，是这样吗？」

要点：**不要在还没开始就挑起争议。** 先问清楚安排，把事实固定下来。如果对方真的不付，你保留后续的救济权利——但**那时需要咨询专业人士，不要自己判断**。

## 5. 五个常见错误

1. **以为签了竞业协议就一定被限制**
   → 后果：白白放弃行业内的好机会，甚至转行，损失远大于风险本身
   → 正确做法：**先确认是否被启动**。绝大多数普通岗位从未被启动过

2. **相信口头承诺"我们不启动"**
   → 后果：这是本节最重要的一条。你入职新公司后，原公司完全可以改口，而你没有凭据
   → 正确做法：书面确认。**邮件、协议条款，任选一种，但必须有文字**

3. **不知道竞业必须给钱**
   → 后果：无偿履行了本不该履行的义务，或者在完全不合理的条件下自我设限
   → 正确做法：启动 = 必须按月支付补偿。**没有补偿而要求你履行，这在法律上是站不住的**（具体以当地裁判口径为准）

4. **把整个行业当成竞业范围**
   → 后果：误以为自己不能在本行业工作，做出过度保守的职业决策
   → 正确做法：竞业限制应当限定在**与本单位生产或经营同类产品、从事同类业务的有竞争关系的特定单位**。范围过宽的部分通常难以得到支持

5. **入职新东家时隐瞒自己有竞业**
   → 后果：新东家在背调或后续纠纷中发现，可能影响你的职业信誉，甚至引发连带纠纷
   → 正确做法：主动、如实说明，并出示你拿到的书面"不启动"确认。**有书面材料在手，这是你的加分项，不是减分项**

## 6. 真实案例（脱敏）

**案例 A：拿到书面确认的人**

某互联网公司，后端开发，离职时 HR 口头说"我们一般不会启动的"。他坚持发了一封邮件要求确认，HR 回复「本次不对你启动竞业限制」。半年后他入职一家直接竞争对手——原公司没有提出任何异议。**那封邮件值了很多钱。**

**案例 B：没拿到书面确认的人**

另一位工程师在同一类情况下只得到口头答复。入职新公司三个月后，原公司发来律师函主张违反竞业。虽然最终因为原公司未支付任何补偿而未能成立，但他经历了数月的焦虑、多次面谈，期间差点被迫离职。**结局没问题，过程很痛。**

两者的差别只有一封邮件。

**案例 C：谈对了方向**

某高级工程师被启动竞业，初始方案是"整个互联网行业、2 年、补偿按当地最低工资"。他没有拒绝，而是谈判把范围缩到"5 家指定公司"，补偿提高到原月薪的一定比例。**结果：他从"两年不能干本行"变成了"两年不能去 5 家公司，且每月有钱拿"。**

## 7. 延伸与依据

- 《中华人民共和国劳动合同法》**第二十三条** —— 保密义务与竞业限制；约定竞业限制的，应在解除或终止劳动合同后，在竞业限制期限内按月给予经济补偿
- 《中华人民共和国劳动合同法》**第二十四条** —— 竞业限制的人员范围（高管、高技及其他负有保密义务人员）；范围、地域、期限由双方约定，不得违反法律；期限不得超过**二年**
