# 期权与未行权：离职窗口期别错过

## 1. 三十秒自检

- [ ] 你有已归属（vested）但还没行权的期权
- [ ] 你不确定离职后还能不能行权、有没有期限
- [ ] 你不太清楚行权需要掏多少钱、要不要交税
- [ ] 你没看过自己的期权协议，也不知道该问谁
- [ ] 你觉得"反正公司没上市，期权就是废纸"

打勾 ≥2 个，往下读。打勾第 5 个的，**尤其要读第 5 段第 1 条**——两个方向上的极端判断都是错的。

## 2. 结论先行

**期权不是免费的钱，它是一个需要用现金去购买的权利，而且买了还要交税。**

离职时最容易被忽略的三件事：

1. **已归属未行权的部分，通常有一个很短的行权窗口**（常见 30~90 天，以你的协议为准）。错过就作废。
2. **未归属部分，离职时通常直接作废**（除非协议另有约定）。
3. **行权需要掏现金 + 缴税。** 这笔钱可能比你想象的大得多，而且**可能不划算**——详见下文。

**最关键的提醒**：不要因为"沉没成本"或"万一公司上市"就盲目掏钱行权。**判断标准只有一个：如果这些期权换成现金让你现在自由选择，你会买吗？** 不会的话，就别买。

## 3. 现在就做

| 时间窗 | 动作 |
|---|---|
| **今天** | 找出期权授予协议（grant agreement），确认三件事：已归属数量、行权价、离职后行权期限 |
| **今天** | 向 HR / 财务发邮件书面确认离职后的期权处理方案（模板见第 4 段） |
| **本周** | 算清行权成本：行权价 × 股数 = 需要掏的现金；再加上可能的税负 |
| **本周** | 判断值不值得行权（见第 5 段第 2 条的三个问题） |
| **本月** | 如果决定不行权：**书面确认并保存记录**，避免日后争议 |
| **本月** | 如果决定行权：在窗口期内完成全部流程，**不要拖到最后一天** |

## 4. 可直接抄的话术 / 模板

**场景一：离职时向 HR 书面确认期权处理（最重要）**

```
主题：关于离职后期权处理事项的确认

XX 您好，

我想确认一下我的期权在离职后的处理方式，麻烦帮忙答复：

1. 截至离职日（YYYY-MM-DD），我的期权已归属数量是多少？未归属多少？
2. 已归属部分的最后行权期限是哪一天？（post-termination exercise period）
3. 行权价格是多少？如需行权，具体流程和付款方式是怎样的？
4. 未归属部分在离职后如何处理？是否有加速归属条款？
5. 若涉及税务，公司在哪些环节有代扣代缴义务？我需要自行申报吗？

感谢您的协助！

XXX
```

要点：**这份邮件的作用是留痕。** 万一后续出现"你过期没行权"的争议，你有凭据说明自己主动核实过。

**场景二：和 HR 沟通行权窗口**

> 「我想确认一下行权窗口的截止日期是不是 X 月 X 日。
> 如果我需要延期行权，公司这边有没有可能通融？我知道这通常很难，但还是想问一下。」

要点：**延期通常是可能的，但只有问了才知道。** 不少公司在友好离职的情况下会给予通融，尤其是你主动、客气地提出时。

**场景三：决定不行权时的书面说明**

```
主题：关于放弃行权的确认

XX 您好，

关于我的期权，经考虑我决定本次不行使行权。
烦请确认：公司是否对我已归属但未行权的部分有其他安排？
如无，我理解这部分将在行权窗口到期后自动失效。

感谢确认！

XXX
```

要点：书面记录能避免未来出现"你当时口头答应要行权"之类的扯皮。

## 5. 五个常见错误

1. **两个方向上的极端判断**
   - 错误 A：觉得"期权就是废纸，全扔了" —— 后果：错过实际有价值的部分
   - 错误 B：觉得"这是我几年辛苦的结晶，一定要保住" —— 后果：掏出一大笔现金买了一堆流动性极差的纸
   → 正确做法：**按当下的客观条件算一笔账**（见下一条），不做情绪化决策

2. **行权前没算清三笔账**
   → 后果：掏了几十万现金，换回来一堆不能变现、还要交税的东西
   → 正确做法：行权前必须回答三个问题：
     - **需要掏多少现金？**（行权价 × 股数）
     - **税负是多少？**（行权时可能产生个人所得税，具体以税务规定为准）
     - **这笔钱如果自己拿着，我会买这家公司的股票吗？**
     如果第三个问题的答案是"不会"——**那就不要行权**。这不是放弃，这是理性决策。

3. **错过行权窗口**
   → 后果：已归属的期权归零，几年的积累变成 0
   → 正确做法：**在日历上标出截止日前 15 天的提醒**。不要相信公司会提醒你——多数公司没有这个义务和习惯

4. **没确认未归属部分的处理**
   → 后果：误以为会自动保留，或者相反，误以为还能继续归属
   → 正确做法：书面确认。**离职员工的未归属部分通常直接作废**，这是行业常态，但你需要确认自己协议里的具体约定

5. **行权后才发现有竞业或回购条款**
   → 后果：行权时才发现协议里有公司回购权、或与其他条款的联动
   → 正确做法：**行权前把协议完整读一遍**，特别注意：回购条款（right of repurchase）、转让限制、税务条款、与其他协议的关联

## 6. 真实案例（脱敏）

**案例 A：理性放弃**

某创业公司，早期员工，4 年积累的已归属期权行权需要一次性掏约 40 万现金，另需缴税。公司当时融资困难，估值已下调。

**做对了什么**：他问了自己第三个问题——"如果我现在有 40 万现金，我会主动买这家公司的股票吗？"答案是不会。他选择了放弃行权，把这笔钱留作失业期的现金流。**一年后公司确实没有好转。**

**做错了什么**：没有，这是这个案例里少见的一次理性决策。

**案例 B：情绪化行权**

另一位工程师在相似情况下觉得"这是我四年的青春"，找家人借了钱行权。结果是：掏空了家里的现金、背上债务、在紧接着的半年求职期里承受了巨大的经济压力，而这批股票至今无法变现。

**如果重来**：期权是补偿，不是身份。**丢了它你不会失去什么，但掏空现金流会让你的求职变得极其被动。**

## 7. 延伸与依据

- 期权的具体条款**以你签署的授予协议（grant agreement）和公司期权计划（plan）为准**，不同公司、不同轮次的条款差异极大
- 期权与 RSU（限制性股票单位）是两种不同的东西：期权是**买的**权利，RSU 是到期直接归属股票
- 个人所得税相关规定以国家税务总局公布的最新政策为准，**行权时点可能产生纳税义务**，建议咨询专业人士
