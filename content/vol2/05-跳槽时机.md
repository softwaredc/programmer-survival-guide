# 跳槽时机：什么时候该走，什么时候该留

## 1. 三十秒自检

- [ ] 你已经连续半年以上没有学到新东西
- [ ] 你想走的原因，说不清是公司、上级还是你自己
- [ ] 你在计算"年终奖还没到手"
- [ ] 你打算先提离职再慢慢找
- [ ] 你现在的简历上这一段还不到一年

打勾 ≥2 个，往下读。**第四第五是操作风险，第一是真正的信号——它们不在一个层面上。**

## 2. 结论先行

**该走的五个信号**（出现两个以上就该认真考虑了）：

1. **停止成长** —— 连续半年以上，你没有做过"当时不会"的事
2. **业务在收缩** —— 团队在缩、预算在砍、项目在被砍
3. **你的可替代性在升高** —— 参见[可替代性自测](02-可替代性自测.md)，分数持续偏低且不涨
4. **薪资严重倒挂** —— 同岗位新人薪资明显高于你，且内部调整无望
5. **上级变了且不认可你** —— 换了一个上级之后你持续被打低分，且沟通无效

**该留的四个信号**：

1. **你正在一个关键项目的中途** —— 做完它，这份经历在简历上才值钱
2. **你在这里有别人给不了的资源** —— 技术方向、导师、数据规模
3. **你还没还清这段经历的"提取成本"** —— 待不到一年的经历往往是负资产
4. **让你想走的是短期情绪** —— 一次委屈、一次争执，通常不是真实原因

**关于"亏了年终奖"这笔账**：
年终奖是沉没成本的分期收款。**用半年甚至一年的成长机会去换一笔确定的钱，通常是不划算的**——除非你的现金流确实紧张。**算总账，不要算单笔账。**

## 3. 现在就做

| 时间窗 | 动作 |
|---|---|
| **今天** | 对照上面的信号，写下你想走的真实原因。**写不出来说明你还没想清楚** |
| **今天** | 检查你想走的原因里，**有多少是公司层面的、有多少是情绪层面的** |
| **本周** | 更新简历，**但不投**——先看市场反馈（可以找猎头或朋友聊，了解自己的定位） |
| **本月** | 先拿到 offer，再提离职。**这个顺序不能反过来**（见第 5 段第 2 条） |
| **提离职前** | 逐项确认第 4 段的"六件事清单" |
| **任何时候** | 每年至少更新一次简历并保持对外可见——**不是为了跳，是为了有校准** |

## 4. 可直接抄的话术 / 模板

### 提离职前必须确认的六件事（逐项打勾）

```
□ 1. 新 offer 已拿到书面版本，薪资结构与条款清楚
□ 2. 社保持续性已确认：新单位的参保起始月份能接上（关系到购房/摇号/落户资格）
□ 3. 竞业状态已确认：是否会被启动（书面确认，见「竞业协议」一章）
□ 4. 期权处理已确认：已归属数量、行权窗口、成本（见「期权与未行权」一章）
□ 5. 背调人已就位：至少 2 位可以作证的人，已提前沟通过
□ 6. 离职时间与交接安排已想清楚：留足交接期，别甩手就走
```

---

**场景一：和上级提离职（体面的开口方式）**

> 「我想和你说一件事。我决定离开，去做一个新的尝试。
> 很感谢这段时间你对我的帮助，我在这里也学到了不少。
> 我会把交接做好，交接期我建议是 X 周，你觉得这样可以吗？」

要点：**先感谢，再表态，然后立刻给交接方案。** 让对方第一时间知道"你不会甩手走人"，气氛会完全不同。

**场景二：被挽留时（保持温和但坚决）**

> 「谢谢，我也很舍不得。不过这个决定我想了挺久，不是一时冲动。
> 所以这次我是确定要走的。交接这块我会负责到底。」

要点：**"我想了很久"这句话很重要**——它关闭了对方继续议价的入口。

**场景三：离职原因的对外统一口径（非常重要）**

> 「主要是想换个方向试试，在 XX 这块想做得更深一些。」

要点：**统一口径、正向表达、不抱怨。** 这一句话你会对几十个人说一遍。**无论真实原因是什么，都用这一个版本。**

**场景四：向猎头或 HR 确认关键信息（避免入坑）**

```
您好，在推进之前我想确认几个问题：

1. 这个岗位的薪资构成是怎样的（base / 绩效 / 年终 / 期权）？试用期薪资是否打折？
2. 社保和公积金的缴纳基数与比例是按什么标准？
3. 是否有竞业限制相关的要求？
4. 背调会联系哪些人？需要我提前准备什么？
5. 入职时间是怎样安排的？我这边需要 X 周的交接期，是否 OK？
```

## 5. 五个常见错误

1. **先提离职再找工作**
   → 后果：这是操作层面的头号错误。失去收入后你的议价能力大幅下降，而且容易在现金压力下接一个更差的 offer
   → 正确做法：**永远先拿 offer 再提离职**

2. **为了年终奖错过最佳时机**
   → 后果：为了两个月的奖金，在一家走下坡的公司多待半年，损失远大于奖金
   → 正确做法：**算总账**。问自己：这半年我损失的机会成本是多少？

3. **不到一年就跳**
   → 后果：简历上出现多段短于一年半的经历，会被用人方打上稳定性标签
   → 正确做法：**除非是明显更上一层楼的机会（职级/方向/薪资大幅跃迁），尽量待满两年**。第一份工作尤其如此

4. **离职时甩手走人**
   → 后果：行业圈子比你想的小。你的交接方式会被记住
   → 正确做法：**留足交接期，做好书面交接**。详见[离职交接与背调](../vol3/08-离职交接与背调.md)

5. **每次跳槽都横向平移**
   → 后果：五年里跳了三次，做的事都一样，薪资有小涨但没有质的变化
   → 正确做法：**每一次跳槽都应该有一个明确的"获得"**——更高的职级、更好的方向、更大的规模。**如果只是换个地方做同样的事，优先谈内部增长**

## 6. 真实案例（脱敏）

**案例 A · 走对了**

某后端工程师，在一家公司待了三年，第三年明显感觉到技术停滞，且团队连续两个季度在砍项目。他在没有提离职的情况下先更新简历并找猎头聊，用两个月拿到了一个做基础架构的机会。职位低半级但方向是他想要的。**四年后他在那个方向上成了稀缺人才。**

**做对了**：早在感受到信号时就开始准备，而不是等到被迫。

**案例 B · 走错了**

另一位工程师因为和直属上级的一次冲突一气之下提了离职，手上没有 offer。之后四个月的求职期内，因为现金流压力接受了一个明显更差的岗位。

**做错了**：① 让短期情绪驱动了重大决策；② 没有 offer 就提离职；③ 没有给自己冷静期。

**他的总结**：「如果我当时给自己两周冷静期，我大概率不会走——那个冲突其实早就过去了。真正让我损失惨重的是后面那四个月的慌张。」

**案例 C · 留对了**

有人两次想跳，都被朋友劝住了——因为他在做一个关键项目的中途。他坚持做完了那个项目（多待了七个月），这份完整的经历让他后来拿到了一个远好于此前的 offer。**"做完它再走"这句话，在很多情况下是对的。**
