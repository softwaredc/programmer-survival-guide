## 使用说明

1. **复制，不要照抄。** 模板是结构，不是内容。把里面的 XX 换成你自己的真实情况。
2. **数字比形容词重要。** 任何地方能加数字就加。
3. **不要发没检查过的模板。** 尤其是涉及金额和日期的邮件，发出前读两遍。

## 也欢迎补模板

如果你有一个自己用过、并且确认有效的模板（比如某种情况下的谈判话术、某种协议的修改措辞），
欢迎提 PR 补充到本目录。

格式要求：

- 不含任何公司名、人名
- 开头用一句话说明"什么时候用"
