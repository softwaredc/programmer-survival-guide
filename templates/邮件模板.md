# 邮件模板合集

> 全部是可直接复制填空的文本。
> **发出前务必读两遍**——尤其是涉及金额、日期、姓名的部分。

---

## 一、沟通后确认（最重要的一类）

### 1.1 通用确认邮件

**什么时候用**：任何一次重要的口头沟通之后，24 小时内发出。

```
主题：关于本次沟通内容的确认

XX 您好，

感谢今天的沟通。为避免理解偏差，我确认一下今天我们谈到的内容：

1. ____
2. ____
3. ____
4. ____

如与您的记录不一致，麻烦回复指出。谢谢。

XXX
```

**为什么它重要**：
- 把口头承诺变成书面记录
- 不需要对方回复——只要发出去，事实就被固定了
- 成本两分钟，可能在几个月后救你一次

---

### 1.2 离职沟通确认

```
主题：关于离职事项的确认

XX 您好，

确认一下今天我们沟通的内容：

1. 拟解除日期：YYYY-MM-DD
2. 补偿方案：XX 个月工资，合计 XX 元
3. 社保与公积金缴纳至：YYYY 年 MM 月
4. 未休年假折算：XX 天，折现 XX 元
5. 加班费结算：____
6. 离职证明中离职原因的表述：协商解除
7. 竞业限制：启动 / 不启动
8. 期权：已归属 ____，最后行权日 YYYY-MM-DD
9. 我的答复时间：YYYY-MM-DD 前

如与您的记录不一致，麻烦指出。感谢！

XXX
```

## 二、要求书面确认

### 2.1 确认竞业是否启动

```
主题：关于离职后竞业限制事项的确认

XX 您好，

关于竞业限制，我需要一个书面确认以便安排后续的职业规划，麻烦帮忙答复：

1. 公司是否对我启动竞业限制？
2. 若启动：限制的范围、期限，以及每月的经济补偿金额分别是多少？
3. 若不启动：是否可以在离职协议中写明「双方确认不启动竞业限制」？

这一项对我接下来的求职非常关键，感谢您的帮助！

XXX
```

### 2.2 确认期权处理

```
主题：关于离职后期权处理事项的确认

XX 您好，

我想确认一下我的期权在离职后的处理方式，麻烦帮忙答复：

1. 截至离职日（YYYY-MM-DD），已归属数量是多少？未归属多少？
2. 已归属部分的最后行权期限是哪一天？
3. 行权价格是多少？如需行权，具体流程和付款方式是怎样的？
4. 未归属部分在离职后如何处理？是否有加速归属条款？
5. 若涉及税务，公司在哪些环节有代扣代缴义务？

感谢您的协助！

XXX
```

### 2.3 要求出具书面解除通知

```
主题：关于解除通知的书面确认

XX 您好，

方便麻烦你把这次的解除安排发一份书面给我吗？
解除原因和最后工作日写清楚就行，我需要留个底。

谢谢！

XXX
```

## 三、求职相关

### 3.1 投递附言

```
主题：应聘 XX 工程师 —— 姓名 —— XX 大学/公司

您好，

附件是我的简历，应聘 XX 岗位。

简单说一下为什么我觉得合适：
· （一条与 JD 匹配的经历，带数字）
· （一条相关的技术点）

感谢您的时间！
姓名 | 电话
```

### 3.2 请求内推

```
主题：XX 岗位内推请求 —— 姓名

学长/学姐（或 XX）你好，

我是 XX 届的 XX，看到贵司 XX 岗位在招，非常想试试。
不知道方不方便帮我内推一下？简历见附件。
不着急，你方便就行。

谢谢！
姓名 | 电话
```

要点：**附上简历（PDF）+ 给对方方便的余地。** 不要发一大段自我介绍。

### 3.3 面试后感谢

```
主题：感谢面试 —— 应聘 XX 岗位 —— 姓名

XX 您好，

感谢您今天的时间。今天的交流让我对这个岗位有了更清楚的了解，
尤其是关于 XX（提到一个具体的、今天聊到的点），我觉得很有意思。

期待有机会一起工作！

姓名 | 电话
```

要点：**24 小时内发，必须提到一个具体细节**（证明你真的在听）。

### 3.4 请求做证明人

```
主题：关于背景调查的一个请求

XX 你好，

我最近在换工作，如果新公司那边做背景调查联系到你，
方便帮我确认一下我的任职时间和岗位吗？
如果你觉得不方便也完全没关系，我理解。

谢谢！另外我的近况是：____

XXX
```

### 3.5 拒绝 offer（留门）

```
主题：关于 XX 岗位 —— 姓名

XX 您好，

非常感谢你们的时间，这个团队我很喜欢。
不过经过考虑，这次因为 XX 原因我不能加入。

希望以后还有机会合作，也祝你们顺利招到合适的人。

XXX
```

## 四、在职相关

### 4.1 向上级表达晋升意愿

```
主题：关于接下来发展方向的一次沟通

XX 你好，

我想和你聊一下我的发展方向。
我的目标是下一次评审能通过（/ 我希望在 XX 方向上做深）。
你觉得以我现在的情况，还差在哪些地方？我想提前准备。

方便约个时间吗？

XXX
```

### 4.2 请求减负（burnout 时用）

```
主题：关于工作节奏的一次沟通

XX 你好，

我想和你聊一下工作节奏的事。

最近几个月我同时在推进 XX 和 XX，加上 XX 的临时需求插入，
我自己的判断是这个节奏不太可持续——质量和投入度都在下降。

我想和你商量一下优先级：这几件事里面，
哪些是可以停一停或者推迟的？

方便约个时间吗？

XXX
```

要点：**说"质量和投入度在下降"，不说"我很累"。**
前者是他关心的业务指标，后者是个人感受。

### 4.3 维护边界（发给协作方）

```
主题：关于消息响应时间的说明

大家好，

同步一下：我一般在晚上 XX 点之后不太会及时处理消息。
如果是紧急的事情可以电话我，其他情况我第二天一早会第一时间处理。

谢谢理解！

XXX
```

要点：**给出替代方案（电话）**，让对方知道不是失联，而是有规则。

## 五、使用原则

```
□ 发出前读两遍，尤其是金额、日期、姓名
□ 语气平和，不带情绪——邮件是留痕的
□ 抄送自己一份（个人邮箱），尤其是涉及离职的
□ 不写任何抱怨、指责、情绪化的话
□ 不确定就先不发，睡一觉再看
```

> 邮件最大的价值不是沟通，是**留痕**。
> 所以每一次重要沟通之后，都应该有一封这样的邮件。
